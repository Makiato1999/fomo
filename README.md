# Fomo

一个面向个人使用的双语术语知识图谱。输入专业术语后，系统将验证术语和语境，生成包含中英文名称、领域、范围、解释、案例与来源的知识节点，并通过关系图、领域树和流程视图组织节点。

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

开发服务器启动后，打开终端输出的本地地址。

第一阶段将知识节点保存为浏览器本地 JSON，并提供导入和导出。清除浏览器数据前请先导出备份。

## 常用命令

```bash
npm run dev
npm run build
npm run lint
```
